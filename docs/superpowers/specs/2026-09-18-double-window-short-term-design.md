# 双窗口超短预案体系设计

日期：2026-09-18

## 目标

在不取消“无前一日收盘预案不交易、不追涨停或连续加速”的风险底线前提下，提高主线切换时的预案覆盖与信号可执行性。

## 已确认参数

- 每日最多4张当前有效执行卡。
- 卡位结构：2张主线卡、1张备选卡、1张次日预布局卡；另设2至3只强弱锚点，仅判断板块，不产生交易资格。
- 上午早期试错窗口：09:30至10:30。
- 下午预布局窗口：13:30至14:30。
- 突破分钟增量成交量门槛：不少于此前3分钟平均增量的1.2倍。
- 每一次早期试错或下午预布局，最多使用该标的计划总仓位的1/3。

## 约束

- 所有执行卡必须在前一日收盘后建立并写清逻辑、攻击位、确认位、失效位及主基准。
- 下午只允许已在当日有效卡中的标的进行次日预布局；不允许将盘中涨幅榜标的临时转为执行卡。
- 涨停、连续加速、高位放量滞涨标的不得进入执行卡。
- 早期试错和下午预布局均须收复主基准、突破攻击位时满足量能门槛，并在攻击位上方保持至少2分钟。
- 失效退出与二次确认继续沿用既有两阶段失败检查。

## 每日流程

1. 前一日收盘后：按2主线、1备选、1预布局卡完成初筛和完整字段。
2. 盘前：隔夜信息仅调整观察优先级，不能改变关键位或临时增加执行卡。
3. 上午：在09:30至10:30验证主线启动或回踩转强的试错条件。
4. 下午：在13:30至14:30验证有效卡的次日预布局条件；未满足则不处理。
5. 收盘后：记录4张卡的五状态结果、板块强弱、信号漏判与预案遗漏，并淘汰不合格标的。
